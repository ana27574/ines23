# 🎮 Gerador de Aventuras Malucas
 
## Objetivo
Criar um programa em C# (Console) capaz de gerar histórias aleatórias utilizando personagens, armas, locais e enredos criados pelo utilizador.
 
## Funcionalidades
- Gerar história aleatória.
- Criar personagens.
- Criar armas.
- Criar locais.
- Criar enredos.
- Registar mudanças.
- Ver estatísticas.
- Sair do programa.
 
## Tecnologias utilizadas
- C#
- .NET Console
 
## Como executar
1. Abrir o projeto no Visual Studio.
2. Executar o ficheiro `Program.cs`.
3. Utilizar o menu apresentado na consola.
 
## Estrutura do menu
 
```
1 - Gerar História Aleatória
2 - Criar Personagem
3 - Criar Arma
4 - Criar Local
5 - Criar Enredo
6 - Fazer Mudanças
7 - Ver Estatísticas
0 - Sair
